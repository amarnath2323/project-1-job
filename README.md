# JobTrack Pro — Final Year Project

Job Application Tracking System for students and job seekers.

## Version
Frontend: HTML5, CSS3, JavaScript
Database design: MySQL
Future backend: Java Spring Boot + JDBC

## Three main windows
1. Dashboard — overview and application pipeline
2. Applications — complete CRUD management
3. Interviews — interview scheduling and preparation

Additional windows:
- Analytics
- Profile

## Features
Dashboard, CRUD, status workflow, search, filters, interview tracker, analytics, career insights, export, responsive UI and database schema.

## Deploy
Upload index.html, style.css and script.js to GitHub.
GitHub → Settings → Pages → Deploy from branch → main → root.

## Database
Run database/schema.sql in MySQL Workbench for the relational database.

## Important architecture
For a real final-year full-stack system:
HTML/CSS/JS → Java Spring Boot REST API → JDBC → MySQL

The supplied static website uses Local Storage only so it can be deployed immediately on GitHub Pages.
